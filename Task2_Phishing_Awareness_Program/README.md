# Task 2 - Phishing Awareness Program
CODSOFT Cyber Security Internship

A single-page, web-based training module that teaches users how to recognise and avoid phishing.

## Contents
- What phishing is (email, spear phishing, smishing, vishing, BEC)
- How to spot suspicious emails (annotated sample with red flags)
- Fake login pages and look-alike domains
- Social engineering techniques (urgency, authority, fear, greed, pretexting, baiting)
- Practical security tips and what to do after clicking
- Case studies: RSA 2011, Google/Facebook invoice fraud, Twitter 2020, KYC SMS scam
- 6-question interactive quiz with instant feedback and a score

## Run it
Open `index.html` in any browser. No install needed.
